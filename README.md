# hifi — Navidrome Web Player

A skinnable web music player for Navidrome (Subsonic API): React frontend, unified Node server (Navidrome proxy + companion + Sonos relay), smart playlists, casting to Google Cast and Sonos.

See `player/README.md` for frontend details and `deploy/` for Docker Compose deployments.
